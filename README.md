# Hola, soy Julián Santiago Hernández Pecha

Data Analyst y administrador de empresas en Bogotá, Colombia. Convierto datos en decisiones de negocio.

## Qué hago
- Limpieza y preprocesamiento de datos
- Análisis exploratorio y estadística
- Dashboards e informes para la toma de decisiones

## Herramientas
SQL · Python (pandas, NumPy, Matplotlib, Seaborn) · Jupyter Notebook · Tableau · Power BI · Excel · Git

- Entender el comportamiento de los clientes y el rendimiento de las ventas
- Presentar hallazgos de forma clara a equipos no técnicos
